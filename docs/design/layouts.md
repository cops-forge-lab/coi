# Layouts e presets

## Preset 01 - Operação normal
- KPI executivo resumido
- Estado dos principais processos/ativos
- Alarmes recentes
- Fontes operacionais prioritárias

## Preset 02 - Incidente
- Fonte afetada ampliada
- Alarmes/eventos
- CFTV relacionado, quando aplicável
- Linha do tempo / contexto operacional

## Preset 03 - Crise
- Visão situacional comum
- Fontes críticas ampliadas
- Canal de coordenação
- Indicadores mínimos para decisão

## Preset 04 - Manutenção
- Saúde dos componentes
- Disponibilidade das fontes
- Diagnóstico de rede/sinal

## Regras visuais
- Reservar a região mais visível para informação prioritária.
- Não reproduzir o mesmo KPI em múltiplos blocos sem necessidade.
- Evitar textos pequenos desenhados para monitor individual.
- Usar cores de alarme de forma consistente e parcimoniosa.
- Projetar cada layout para distância real de leitura.
