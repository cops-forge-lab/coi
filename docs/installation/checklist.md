# Checklist de instalação

## Antes
- [ ] Parede/estrutura liberada pelo responsável técnico
- [ ] Energia final disponível
- [ ] Rede final disponível
- [ ] Climatização operacional
- [ ] Equipamentos conferidos por modelo e serial
- [ ] Displays inspecionados antes da montagem
- [ ] Rotas de cabos liberadas

## Mecânica
- [ ] Estrutura nivelada e aprumada
- [ ] Fixação conforme projeto
- [ ] Painéis instalados sem pressão indevida
- [ ] Folgas e ventilação conforme fabricante
- [ ] Acesso para manutenção validado

## Elétrica e sinal
- [ ] Circuitos identificados
- [ ] Aterramento validado pelo responsável
- [ ] Cabos identificados nas duas pontas
- [ ] Fontes testadas individualmente
- [ ] Presets carregados

## Fechamento
- [ ] Fotos técnicas registradas
- [ ] As-built atualizado
- [ ] Seriais registrados
- [ ] Backup da configuração salvo
- [ ] Aceite de instalação assinado
