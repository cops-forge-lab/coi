# Rede AV

## Checklist de projeto
- Levantar bitrate e quantidade de fluxos.
- Separar tráfego AV quando necessário.
- Planejar VLANs conforme política corporativa.
- Validar multicast/IGMP quando a tecnologia AV-over-IP exigir.
- Dimensionar uplinks e oversubscription.
- Sincronizar NTP.
- Restringir interfaces administrativas.
- Definir monitoramento dos endpoints.
- Documentar portas e patch panels.

Não registrar endereços IP produtivos neste repositório público/reutilizável.
